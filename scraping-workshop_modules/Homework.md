# 📝 Web Scraping Project — Homework

Create a **small web scraping project of your choice** using the concepts covered in the workshop.

Your project can involve:

- Extracting different HTML elements
- Extracting links and URLs
- Extracting images
- Extracting tables
- Exploring/following links
- Scraping information from multiple pages

You are free to choose the **website, type of data, project idea, and how you present the results**.

## 💡 Small Web Scraping Project Ideas

### 1. 📚 Book Explorer
- Scrape book titles, prices, ratings, and links.
- Explore individual books by following their links.

### 2. 🎬 Movie Explorer
- Scrape movie titles, ratings, release years, genres, etc.
- Follow links to get more details about selected movies.

### 3. 🍳 Recipe Finder
- Scrape recipe names, ingredients, cooking time, and images.
- Follow a recipe link to get its details.

### 4. 📰 News Explorer
- Scrape article titles, descriptions, dates, and links.
- Allow users to select an article and scrape its contents.

### 5. 🐾 Animal Explorer
- Scrape animal names, descriptions, images, and other information.
- Follow links to explore individual animals.

## ⭐ Bonus

Add a simple **UI** to your project and allow users to interact with the scraped data.
